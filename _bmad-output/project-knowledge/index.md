## Project Overview

`xiaomang` 是一个面向内容运营场景的工作台。它把抖音链接批量解析、Coze 工作流内容生成、可选翻译与平台风格转写、最终文案编辑与导出串成一条连续流程，并同时提供本地 Node 代理模式与 `api/` Serverless 部署模式。

## Quick Reference

- **Tech Stack:** React 18, React Router 7, Vite 6, Tailwind 4, Radix UI, Express 5, Vercel-style serverless handlers
- **Entry Point:** `src/main.tsx`
- **Architecture Pattern:** 前端单页应用 + 代理后端 + 第三方 AI/数据服务集成
- **Database:** 无正式数据库；本地 Node 模式使用 `server/data/final-drafts.json`，Serverless 模式使用内存 Map
- **Deployment:** `dist/` 静态资源 + Nginx 反向代理到 `server/index.js`，或使用 `api/` 目录的无服务函数

### Prerequisites

- Node.js 18+

### Setup

```bash
npm i
cp .env.example .env
cp server/.env.example server/.env
```
